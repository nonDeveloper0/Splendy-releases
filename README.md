# Splendy 다운로드

Splendy의 설치 파일과 업데이트 안내를 제공하는 공개 배포 전용 저장소입니다. 앱 소스코드와 개발 이력은 포함하지 않습니다.

- [웹에서 플레이](https://splendy.pjwater727.workers.dev)
- [Android APK 다운로드 · 1.0.2 미리보기](https://github.com/nonDeveloper0/Splendy-releases/releases/download/v1.0.2-preview.1/splendy-android.apk)
- [릴리스 목록](https://github.com/nonDeveloper0/Splendy-releases/releases)

## Android

`*.apk` 파일을 Android 기기에서 다운로드해 설치하세요. 기존 테스트 인증서로 서명한 미리보기 빌드입니다. 정식 서명 배포는 준비 중입니다.

Android에서 요청하는 경우 다운로드에 사용한 브라우저 또는 파일 앱에 앱 설치를 허용해야 합니다. 릴리스의 `SHA256SUMS.txt`로 설치 파일을 검증할 수 있습니다.

## iPhone / iPad

iOS 네이티브 앱은 아직 제공하지 않습니다. Safari에서 웹 주소를 열고 공유 메뉴의 **홈 화면에 추가**를 선택하세요. **웹 앱으로 열기** 옵션이 있으면 켜 주세요.

## 지원

게임 규칙과 튜토리얼은 웹·앱 안에서 확인할 수 있습니다. 이 저장소에는 설치 파일, 체크섬, 배포 안내만 게시합니다.
