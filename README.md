# 💎 Splendy

보드게임 스플렌더를 모바일과 웹에서 즐길 수 있도록 만든 **Splendy**입니다.

이 저장소는 Splendy의 설치 파일과 업데이트를 배포하기 위한 공간입니다. 소스코드는 포함되어 있지 않습니다.

## 🧪 1.0.4 업데이트 연결 테스트

1.0.4는 **1.0.3에서 업데이트 안내와 APK 다운로드 연결을 확인하기 위한 배포**입니다. 기능은 1.0.3과 같습니다.

1. 1.0.3이 설치된 상태에서 앱을 완전히 종료하고 다시 실행합니다.
2. 업데이트 팝업에서 **다운로드**를 누릅니다.
3. 브라우저에서 APK 다운로드가 시작되는지 확인한 후 설치합니다.
4. 1.0.4를 다시 실행했을 때 같은 업데이트 안내가 뜨지 않으면 완료입니다.

**나중에**도 시험하려면 1.0.4 설치 전에 먼저 눌러 보세요. 앱을 계속 사용할 수 있고, 앱을 완전히 종료한 뒤 다시 실행하면 업데이트를 다시 안내합니다. 홈 화면으로 나갔다가 돌아오는 것만으로는 업데이트를 다시 확인하지 않습니다.

테스트 시작용 [1.0.3 APK](https://github.com/nonDeveloper0/Splendy-releases/releases/download/v1.0.3-preview.1/splendy-android.apk)도 유지합니다. 1.0.4를 이미 설치했다면 1.0.3을 유지 중인 다른 기기에서 테스트해 주세요.

## ✨ 1.0.3 업데이트

- **업데이트 안내:** Android 앱 실행 시 새 버전이 있으면 **다운로드 / 나중에** 팝업을 표시합니다.
- **게임 중 설정:** 상단 톱니바퀴 버튼에서 음량(0~100%)과 진동 세기(약·보통·강)를 조절할 수 있습니다. 설정은 저장되며, 창을 닫으면 게임을 계속 진행합니다.
- **UI 개선:** 하늘색 다이아몬드 재화 아이콘, 입체감 있는 버튼과 그림자, 상점 테마 미리보기 개선을 적용했습니다.
- **감정 표현:** Microsoft Fluent 3D 이모티콘을 적용했습니다.
- **튜토리얼:** 선택할 영역만 밝게 표시하고 나머지 영역의 입력을 차단합니다.

업데이트 안내 기능은 **1.0.3을 먼저 설치한 후부터** 사용할 수 있습니다. 1.0.2 이하 사용자는 위 APK 링크로 직접 업데이트해 주세요. 1.0.3 설치 후에는 더 높은 버전이 게시되면 앱에서 안내합니다.

위 변경 사항은 Android 1.0.3 기준입니다. 웹 버전의 반영 시점은 다를 수 있습니다.

## 📱 설치 방법

**Android**

1. 위 링크에서 APK 파일을 다운로드합니다.
2. 다운로드한 APK 파일을 실행합니다.
3. 설치 권한을 요청하면 허용한 후 설치를 진행합니다.

현재는 테스트 버전으로 배포 중이며, 정식 배포는 준비 중입니다.

기존 설치와 같은 서명 인증서를 사용하므로 앱을 삭제하지 않고 업데이트할 수 있습니다. 다운로드한 APK를 열고 Android의 설치 안내를 따라 주세요.

**iPhone / iPad**

iOS 앱은 아직 준비 중이지만 웹 브라우저에서 플레이할 수 있습니다.

1. Safari에서 [Splendy 웹사이트](https://splendy.pjwater727.workers.dev)에 접속합니다.
2. 공유 버튼을 누르고 **홈 화면에 추가**를 선택합니다.
3. 홈 화면에 추가된 Splendy를 실행합니다.

## 📢 안내사항

- 현재 개발 중인 버전으로, 일부 오류가 발생할 수 있습니다.
- 게임 규칙과 플레이 방법은 게임 내에서 확인할 수 있습니다.
- 새로운 버전은 GitHub Releases를 통해 배포합니다.
- Android APK 파일은 릴리스에 포함된 `SHA256SUMS.txt`로 무결성을 확인할 수 있습니다.
